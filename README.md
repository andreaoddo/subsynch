# Subsynch

Subsynch is an Angular-based web application designed for the creation, editing, and precise synchronization of subtitles. Inspired by VisualSubSync, it provides a clean, minimal user interface to ensure subtitles are perfectly timed and highly legible.

## Features

* **Waveform-Driven Interface:** Extracts and displays audio waveforms from video files, allowing users to select areas directly on the waveform to add or adjust subtitles.
* **Comprehensive Editing Tools:** Create new subtitles, or modify, delete, merge, and split existing ones.
* **Visual Synchronization:** Drag the start and end points of any subtitle directly on the timeline for precise frame-level adjustments.
* **Batch Time-Shifting:** Apply bulk time offsets to resynchronize entire subtitle tracks for different video releases.
* **Legibility Analysis:** Built-in metrics to evaluate if subtitles are too fast, too slow, or perfectly timed for optimal reading speed.
* **Format Support:** Fully supports SubRip (`.srt`) files, with architecture in place to support additional formats in the future.
